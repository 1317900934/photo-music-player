# 🎞️ Photo Music Player

将照片和音乐打包成一个音乐相册来收藏，随时播放观看。

## 功能

- **创建音乐相册** — 选择至少一张照片，音乐可选，打包为pmb格式文件
- **编辑音乐相册** — 选择一个pmb文件进行编辑，修改名称、添加/删除照片和音乐
- **播放音乐相册** — 打开已打包的pmb文件，欣赏图片与音乐
- **拆解音乐相册** — 选择一个pmb文件进行拆解，还原为原本的照片和音乐文件

## 启动

- 运行"音乐相册.exe"

## 格式说明

`.pmb` 本质是一个 zip 包：

```
相册.pmb
├── manifest.json          # 元数据（标题、图片/音乐清单）
└── assets/
    ├── 0001_xxx.jpg       # 图片文件（按列表顺序从 0001 编号）
    └── 0001_yyy.mp3       # 音乐文件（按列表顺序从 0001 编号）
```

序号前缀只存在于 pmb 包内部，界面显示和拆解还原时均为原始文件名。

## 依赖

- Python 3.10+
- PySide6
