# 🎞️ Photo Music Player

将照片和音乐打包成 `.pmb` 音乐相册，随时播放回忆。

## 功能

- **创建音乐相册** — 选择多张照片 + 背景音乐，打包为 `.pmb` 文件
- **播放音乐相册** — 打开已打包的`.pmb` 文件，照片轮播 + 音乐播放，支持拖拽打开
- **拆解音乐相册** — 将 `.pmb` 还原为独立的照片和音乐文件

## 启动

- 运行"音乐相册.exe"

## 格式说明

`.pmb` 本质是一个 zip 包：

```
相册.pmb
├── manifest.json          # 元数据（标题、图片/音乐清单）
└── assets/
    ├── 000_xxx.jpg        # 图片文件
    └── 001_yyy.mp3        # 音乐文件
```

## 依赖

- Python 3.10+
- PySide6
